Проблема

  • Срыв плазмы в токамаке = ущерб $50 000 — 500 000 за событие
  • ITER — международный термоядерный реактор (500 MW), Россия — участник проекта
  • Необходимо предсказывать срывы за 100—500 мс до события
  • Существующие решения — изолированные модели без единой платформы
  • Нет российских веб-платформ для ML-анализа данных токамаков

Цель работы

Разработать первую в России веб-платформу для ML-анализа экспериментальных данных токамаков с загрузкой данных из международных архивов, интерактивной визуализацией и предсказанием срывов плазмы.

2

Решение — Tokamak Analysis

Первая в России веб-платформа для ML-анализа данных токамаков

  • Загрузка данных из FAIR-MAST (11 573 экспериментальных выстрела)
  • 3 ML-архитектуры: Random Forest, bi-LSTM+Attention, Transformer
  • Интерактивная визуализация параметров плазмы (Plotly.js)
  • Предсказание срывов + рекомендации по стабилизации
  • Open-source, Docker, 100% покрытие функциональных требований

Результаты ML-моделей — кросс-валидация

3-fold кросс-валидация, датасет: 500 выстрелов × 200 шагов × 20 признаков

Модель CV Accuracy CV AUC-ROC Test Acc Test AUC P99 Латентность
Random Forest 98.4% ± 0.8% 0.983 ± 0.012 100% 1.000 73 мс
bi-LSTM+Attention 78.4% ± 0.9% 0.867 ± 0.013 80% 0.944 39 мс
Transformer 87.8% ± 1.0% 0.938 ± 0.034 100% 1.000 131 мс

Ключевые выводы

  • LSTM+Attention — лучшая модель при полном обучении (AUC 0.9938, 50 эпох)
  • Random Forest — лучший CV AUC (0.983), наиболее устойчив к временному сдвигу
  • Transformer — второе место (AUC 0.938), лучшая обобщающая способность
  • Инференс: ~19 мс (чистый ML), 500 выстрелов для обучения

Данные FAIR-MAST

Источник

  • 11 573 экспериментальных выстрела
  • Токамак MAST (Великобритания, UKAEA)
  • Формат: Zarr/S3 (открытый доступ)
  • 10 EFM-сигналов равновесия плазмы

Сигналы

  • Ток плазмы (Ip)
  • Электронная плотность (ne)
  • Температура плазмы
  • Магнитные параметры (Bt, q95)
  • Геометрия плазмы (элонгация, триангулярность)

Предобработка

  • Min-max нормализация
  • Линейная интерполяция пропусков
  • Ресемплинг к единой временной сетке
  • Скользящее окно 30 мс для меток

Безопасность и качество

Безопасность

  • JWT-аутентификация + refresh token rotation
  • bcrypt (cost factor 12), RBAC (3 роли)
  • OWASP-сканирование: 15/16 проверок PASS
  • 152-ФЗ: согласие на обработку ПДн
  • Аудит-лог всех действий
  • Rate limiting, CORS, CSP headers

Тестирование

  • 205 автотестов (unit + integration + E2E)
  • CI/CD через GitHub Actions
  • Покрытие кода 81%
  • Линтинг: Ruff (Python), ESLint (TS)

Мониторинг

  • Prometheus + Grafana (2 дашборда)
  • 10 алертов + Telegram-бот
  • Structured logging (JSON)
