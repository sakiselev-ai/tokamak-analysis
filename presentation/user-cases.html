Роли пользователей

Система поддерживает три роли с различными правами доступа (RBAC):

Исследователь (researcher)

  • Загрузка экспериментальных данных из FAIR-MAST
  • Интерактивная визуализация временных рядов (Plotly.js)
  • Классификация плазменного режима (stable / unstable)
  • Экспорт результатов в CSV / JSON

Инженер токамака (engineer)

  • Предсказание срывов плазмы с визуализацией вероятности
  • Физически обоснованные рекомендации по стабилизации
  • Настройка порогов срабатывания предупреждений

Администратор (admin)

  • Управление пользователями: создание, смена ролей, деактивация
  • Аудит-лог всех действий пользователей (67+ записей)
  • Мониторинг: Grafana-дашборды, Prometheus-алерты, Telegram-бот
2

Кейс 1 — Исследователь анализирует выстрел

  1. Регистрация в системе (admin@mephi.ru, согласие на обработку ПДн по 152-ФЗ)
  2. Ввод Shot ID на странице экспериментов (например, 11700)
  3. Загрузка данных из FAIR-MAST (S3 / Zarr, ~6 сек на предобработку 229 сигналов)
  4. Визуализация временных рядов параметров плазмы (Plotly: зум, hover, выбор сигналов)
  5. Классификация плазменного режима: stable / unstable + confidence score
  6. Экспорт данных и результатов в CSV или JSON

Кейс 2 — Инженер предсказывает срыв

  1. Вход в систему с ролью engineer
  2. Выбор загруженного эксперимента из списка
  3. Запуск предсказания срыва (кнопка «Предсказать срыв»)
  4. График вероятности срыва во времени (DisruptionChart, Plotly.js)
  5. Порог срабатывания предупреждения (красная зона на графике)
  6. Рекомендации по стабилизации: снижение тока, газонапуск, коррекция формы плазмы
  7. Настройка порога: Settings → threshold (персональный для каждого пользователя)

Рекомендации системы

  • Снижение тока плазмы (Ip)
  • Увеличение газонапуска
  • Коррекция формы плазмы
  • Физически обоснованы на основе feature importance

Визуализация

  • Временная шкала вероятности срыва
  • Пороговая линия (настраиваемая)
  • Зелёная / жёлтая / красная зоны
  • Интерактивный hover с точными значениями

Кейс 3 — Обучение новой модели

  1. Страница Training → выбор архитектуры: Random Forest / LSTM / Transformer
  2. Настройка гиперпараметров (n_estimators, num_layers, attention_heads и др.)
  3. Запуск обучения (асинхронно через Celery, не блокирует UI)
  4. Отслеживание прогресса в реальном времени (polling каждые 3 сек)
  5. Просмотр финальных метрик: accuracy, F1, AUC-ROC
  6. Активация лучшей версии модели для использования в предсказаниях

Кейс 4 — Пакетная обработка

  1. Страница Batch → ввод диапазона Shot ID (например, 11700 — 11720)
  2. Массовая загрузка данных из FAIR-MAST (параллельная обработка)
  3. Batch classify → таблица результатов классификации для всех выстрелов
  4. Batch disruption → сводка предсказаний срывов по всем выстрелам

Кейс 5 — Администрирование

  1. Управление пользователями: /admin/users — список всех аккаунтов
  2. Смена ролей: researcher ↔ engineer ↔ admin
  3. Деактивация аккаунтов (soft delete, соответствие 152-ФЗ)
  4. Просмотр аудит-лога: 67+ записей всех действий с IP-адресами
  5. Мониторинг: Grafana-дашборды, Prometheus-алерты, Telegram-бот

Аудит-лог

  • Авторизации и регистрации
  • Загрузки экспериментов
  • Запуски предсказаний
  • Изменения ролей и настроек
  • IP-адрес каждого действия

  • APIDown, MLServiceDown
  • HighLatency, HighErrorRate
  • DiskSpace, PostgresDown
  • LongTraining, AccuracyDrift
  • HighMemory, CeleryBacklog

Быстрый старт

  1. Откройте tokamak-ai.ru
  2. Войдите как admin@mephi.ru

  4. Нажмите «Загрузить»
  5. Используйте визуализацию и ML

Локальный запуск

  1. git clone репозитория
  2. docker compose up -d
  3. 12 сервисов поднимаются за ~2 мин
  4. Откройте http://localhost
