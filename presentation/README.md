# Презентационные материалы — Tokamak Analysis

Материалы для демонстрации проекта на конкурсе "Код МИФИста".

## Содержимое

| Файл | Описание |
|------|----------|
| `slides.md` | Презентация (12 слайдов), формат Marp |
| `demo_script.md` | Сценарий живой демонстрации (5 минут) |

## Сборка презентации

### Установка Marp CLI

```bash
npm install -g @marp-team/marp-cli
```

### Генерация PDF

```bash
marp slides.md --pdf --allow-local-files -o slides.pdf
```

### Генерация HTML

```bash
marp slides.md --html -o slides.html
```

### Генерация PPTX

```bash
marp slides.md --pptx -o slides.pptx
```

### Режим предпросмотра

Запуск локального сервера с автообновлением при редактировании:

```bash
marp -s slides.md
```

Презентация будет доступна по адресу http://localhost:8080/.

## Настройка темы Marp

Презентация использует тёмную тему с цветовой схемой:

- Фон: `#1a1a2e` (тёмно-синий)
- Акцент: `#e94560` (красный)
- Текст: `#ffffff` (белый)
- Ссылки: `#4ecdc4` (бирюзовый)
- Код: `#16213e` фон, `#4ecdc4` текст

Для изменения стилей отредактируйте блок `style` в заголовке `slides.md`.
