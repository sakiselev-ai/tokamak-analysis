# Tokamak Analysis

## ИИ-система для анализа экспериментальных данных токамаков

### НИЯУ МИФИ, 2026

---

# Проблема

- **Срыв плазмы** в токамаке = ущерб **$50 000 -- 500 000** за событие
- **ITER** — международный термоядерный реактор (500 MW), Россия — участник проекта
- Необходимо предсказывать срывы за **100--500 мс** до события
- Существующие решения — изолированные модели без единой платформы
- Нет российских веб-платформ для ML-анализа данных токамаков

---

# Решение

**Tokamak Analysis** — первая в России веб-платформа для ML-анализа данных токамаков

- Загрузка данных из **FAIR-MAST** (11 573 экспериментальных выстрела)
- **3 ML-архитектуры:** Random Forest, bi-LSTM+Attention, Transformer
- Интерактивная визуализация параметров плазмы (Plotly.js)
- Предсказание срывов + рекомендации по стабилизации
- Open-source, Docker, **100% покрытие** функциональных требований

---

# Архитектура системы

```
                    Nginx (reverse proxy)
                    /        |        \
              React 18    FastAPI    Grafana
              (SPA)      (API+ML)   (мониторинг)
                           |
              +------------+------------+
              |            |            |
          PostgreSQL    Redis       MinIO
          (данные)    (кэш/очереди) (модели)
              |            |
          Alembic     Celery Workers
        (миграции)   (обучение ML)
```

**12 Docker-сервисов** | **4 сети** | Модульный монолит + ML-сервис

---

# ML-модели

| Модель | Accuracy | AUC-ROC | Латентность |
|--------|----------|---------|-------------|
| Random Forest | 96.7% (CV) | 1.00 | 55.5 мс |
| bi-LSTM+Attention | 100% | 1.00 | 6.4 мс |
| Transformer | 93.3% | 1.00 | 4.9 мс |

- Обучено на **150 реальных выстрелах** токамака MAST
- Кросс-валидация (5-fold) для Random Forest
- Архитектурное решение задокументировано в **ADR-004**

---

# Данные FAIR-MAST

- **11 573** экспериментальных выстрела токамака MAST (Великобритания)
- **10 EFM-сигналов** равновесия плазмы:
  - Ток плазмы, плотность, температура
  - Магнитные параметры, форма плазмы
- Формат: **Zarr/S3** (открытый доступ UKAEA)
- Предобработка:
  - Min-max нормализация
  - Линейная интерполяция пропусков
  - Ресемплинг к единой временной сетке

---

# Визуализация и анализ

**Интерактивные графики Plotly.js:**
- Временные ряды параметров плазмы
- Масштабирование, pan, hover с точными значениями
- Выбор отображаемых сигналов

**ML-классификация:**
- Определение стабильности плазменного режима
- Confidence score для каждого предсказания
- Рекомендации по стабилизации плазмы

**Обучение моделей:**
- Выбор архитектуры и гиперпараметров через UI
- Асинхронное обучение (Celery)
- Версионирование моделей (MinIO)

---

# Безопасность и compliance

- **JWT-аутентификация** + refresh token rotation
- **bcrypt** (cost factor 12), **RBAC** (3 роли: исследователь, инженер, админ)
- **OWASP-сканирование:** 15/16 проверок PASS
- **152-ФЗ:** согласие на обработку ПДн, право на удаление данных
- **Аудит-лог** всех действий пользователей
- Rate limiting, CORS, CSP headers
- Валидация входных данных на всех эндпоинтах

---

# Мониторинг и качество

**Мониторинг:**
- Prometheus + Grafana (**7 панелей** мониторинга)
- Alertmanager с оповещениями в **Telegram**
- Structured logging (JSON-формат)

**Тестирование:**
- **73 автотеста** (unit + integration + security)
- CI/CD через **GitHub Actions**
- Покрытие кода **80%+**
- Линтинг: Ruff (Python), ESLint (TypeScript)
