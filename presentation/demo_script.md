**Продолжительность:** 5 минут
**Формат:** живая демонстрация веб-приложения
**URL:** https://tokamak-ai.ru

---

## Вступление (30 сек)

"Добрый день! Представляю проект Tokamak Analysis — ИИ-платформу для анализа экспериментальных данных токамаков. Платформа позволяет загружать данные реальных экспериментов, визуализировать параметры плазмы и предсказывать срывы с помощью нейросетей."

**Ключевые тезисы:**
- Срыв плазмы в токамаке — это аварийное событие, которое может повредить стенку реактора
- Для будущих установок (ITER) предсказание срывов критически важно
- Наша платформа объединяет данные, визуализацию и ML в одном инструменте

## Запасные ответы на вопросы

**В: Почему MAST, а не российские токамаки?**
О: FAIR-MAST — единственный открытый архив с полными данными. Архитектура платформы позволяет подключить любой источник данных, включая МИФИСТ и Т-15МД.

**В: Какие результаты моделей?**
О: Random Forest AUC 0.9677, LSTM+Attention AUC 0.9938, Transformer AUC 0.9415. Обучены на 500 выстрелах MAST. Temporal validation показывает, что RF наиболее устойчив к сдвигу данных (AUC 0.969).

**В: Как масштабируется система?**
О: Docker-архитектура с 4 сетями позволяет горизонтально масштабировать сервисы. Celery workers можно добавлять для параллельного обучения моделей.

**В: Какие аналоги существуют?**
О: FREIA (JET), DPRF (DIII-D) — это отдельные модели, не платформы. Наше решение — первая в России интегрированная веб-платформа для ML-анализа данных токамаков.

**В: Безопасность?**
О: OWASP-сканирование 15 из 16 проверок пройдено, JWT с ротацией токенов, bcrypt с cost factor 12, RBAC, аудит-лог, соответствие 152-ФЗ.
