# Регистрация ПО в Роспатенте

## Что нужно
1. Заявление (форма РП)
2. Депонируемые материалы (исходный код, 50 стр.)
3. Реферат
4. Госпошлина: 3 000 ₽
5. Документ об оплате

## Подача
- Через Госуслуги: gosuslugi.ru → Роспатент → Регистрация программы для ЭВМ
- Или через ФИПС: fips.ru

## Сроки
- Рассмотрение: ~2 месяца
- Регистрация: ~3-4 месяца
