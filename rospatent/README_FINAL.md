## Инструкция по подаче в ФИПС

### Вариант 1. Электронная подача (рекомендуется)

1. Перейти на портал ФИПС: https://new.fips.ru/
2. Авторизоваться через ЕСИА (Госуслуги) или учетную запись ФИПС.
3. Выбрать услугу: **Государственная регистрация программы для ЭВМ**.
4. Заполнить электронную форму заявления по данным из `application_form.md`.
5. Прикрепить файлы:
   - Реферат (сформировать PDF из `referat.md`)
   - Депонируемые материалы (`deposited_listing.txt` — конвертировать в PDF)
6. Оплатить госпошлину 3 000 руб. (при электронной подаче возможна скидка 30%).
7. Подписать заявление усиленной квалифицированной электронной подписью (УКЭП).
8. Отправить заявку.

### Вариант 2. Подача на бумажном носителе

1. Распечатать заявление (`application_form.md` — 2 листа).
2. Распечатать реферат (`referat.md` — 2 листа).
3. Распечатать листинг (`deposited_listing.txt` — ~28 листов).
4. Заполнить от руки поля [ФИО], [ОГРН], [ИНН] и т.д.
5. Подписать заявление, поставить печать организации.
6. Приложить платежное поручение об уплате госпошлины.
7. Направить комплект документов по адресу:
   **ФИПС, Бережковская набережная, д. 30, к. 1, Москва, 121059**
   или подать лично в окно приема.

### Вариант 3. Через Госуслуги

1. Перейти на https://www.gosuslugi.ru/
2. Найти услугу: «Государственная регистрация программы для ЭВМ».
3. Следовать инструкциям портала.

## Важные замечания

- **Перед подачей** необходимо заполнить все поля, отмеченные как `[указать ...]` в заявлении и реферате (ФИО авторов, ОГРН, ИНН, КПП, контакты).
- **Госпошлина** составляет 3 000 руб. для юридических лиц. При электронной подаче через портал ФИПС действует скидка 30% (2 100 руб.).
- **Срок рассмотрения** — до 62 рабочих дней с даты поступления заявки в ФИПС.
- **Результат** — свидетельство о государственной регистрации программы для ЭВМ и запись в Реестре программ для ЭВМ.
- Листинг исходного кода при печати должен быть оформлен шрифтом фиксированной ширины (Courier New, 10 pt), с нумерацией страниц.

## Генерация листинга

Листинг можно перегенерировать с помощью скрипта:

```bash
python3 rospatent/deposited_code.py --output rospatent/deposited_listing.txt --project-root .
```

Скрипт автоматически включает ключевые файлы и при необходимости обрезает до 50 страниц (первые 25 + последние 25).
